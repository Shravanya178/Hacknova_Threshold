# Threshold — Demo Script (Final)
### Target: 110–130 seconds. Two users, one shared trigger, two different diagnoses.

---

## [0:00–0:10] Opening frame

**Say:**
> "Meet two people. Both just typed the exact same sentence into Threshold:
> 'I want to become a confident product designer.'
> Every other app in this room will show them the same thing. Ours won't — and it'll tell you why."

*(Screen: two blank profile cards, side by side, same input text under both.)*

---

## [0:10–0:40] User 1 — Aarav

**Say:**
> "This is Aarav."

*(Open Identity Conversation for Aarav.)*

**AI asks:** "What kind of designer do you want to become?"
**Aarav replies:** "I want confidence during interviews."

**Say, over the reasoning trace appearing on screen:**
> "Threshold doesn't hear 'design.' It hears the gap underneath it."

*(Screen shows the trace: Identity → Intent → Capability Gap → Readiness, landing on: **Capability Gap: Communication Confidence, not UI Skill** — and quadrant: **Commitment** — high energy, wants structure.)*

**Journey composes on screen — not courses, an experience:**
> Attend a Design Critique → Ask one question → Meet the mentor → Apply the feedback → Reflect

**Say:**
> "No course. An experience, sequenced."

---

## [0:40–1:10] User 2 — Meera (the contrast — this is the point of the demo)

**Say:**
> "Same words. Meera."

*(Open Identity Conversation for Meera — same opening question.)*

**Meera replies:** "I want confidence during interviews... I've been rejected four times this month."

**Say, over her trace appearing:**
> "Same sentence as Aarav. Completely different moment."

*(Screen shows: quadrant **Compassion** — low energy, external attribution rising in her recent reflections — not a skills gap, a capacity gap.)*

**Journey composes — visibly different, visibly gentler:**
> No external ask today → One reflection prompt: "What did the last rejection actually cost you?" → One low-stakes portfolio review, self-paced, zero deadline

**Say:**
> "Aarav gets pushed toward people. Meera gets protected from them — for now. Same goal. Same words. The system didn't recommend twice. It diagnosed twice."

---

## [1:10–1:30] Explainability — "Why This?"

*(Judge, or presenter, clicks "Why This?" on Aarav's journey.)*

**Modal shows:**
> "You already demonstrated design competence — three past projects, no confidence gap in the work itself. The gap shows up only in social/interview contexts. **Why not more UI content?** You don't need it. Adding it now would avoid the actual gap, not close it."

**Say:**
> "It also tells you what it *didn't* recommend, and why. No black box."

---

## [1:30–1:45] Experience Composer, named

**Say:**
> "Every journey step you just saw is an experience, not a resource — attend, ask, meet, apply, reflect. Media is one ingredient. It's never the whole dish."

---

## [1:45–2:05] Close

**Say:**
> "Two users. One sentence. Two diagnoses. That's not a recommendation engine with better labels — that's a system that knows the difference between a skill gap and a moment.
>
> Threshold will never become another social network, another habit tracker, another LMS, another AI companion. It does one thing: it composes the next meaningful growth experience — for whoever you actually are today, not whoever typed the goal."

*(Optional, if time allows — static slide, not live: one-line Social Impact note — "Two users, one real mentor-eligible evidence trail already generated." Cut first if running over time.)*

---

## Presenter notes
- If running long, cut the Experience Composer beat (1:30–1:45) before you cut Meera. The contrast *is* the pitch — everything else supports it.
- Keep both journeys visually distinct on screen simultaneously if possible (split screen or fast toggle) so the judges see the divergence, not just hear it described.
- Confirm before rehearsal: does the built system actually output "Capability Gap" *and* the quadrant label together, or only one? The script uses both — make sure the live demo matches whichever the system truly shows.
